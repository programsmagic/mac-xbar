# UI Polish Plan — mac-xbar v1.2

## Goal
Transform the app from a basic menu bar utility into a polished, first-party macOS experience matching the design guide.

## Changes

### 1. Menu Bar Compact Mode with Network Speed
- **File**: `Sources/App/App.swift`
- Update `refreshAllModules()` to extract download/upload speed from NetworkModule output
- Call `menuEngine?.setTitle("↓\(dl) ↑\(ul)")` to show speed in menu bar title
- Format: `↓12.4M ↑2.1M` (auto-scaled units)
- Add `extractNetworkSpeed(from:)` helper to parse speed items

### 2. Width Stabilization
- **File**: `Sources/MenuEngine/MenuEngine.swift`
- Add `fixedWidth` property to `MenuEngine`
- When `compactMode` is true, set `statusItem.length` to a fixed value
- Calculate width based on title length + icon width + padding
- Prevent menu bar jitter when values change

### 3. Theme Support (Light/Dark/System)
- **File**: `Sources/Core/Models.swift`
- Add `Theme` enum: `system`, `light`, `dark`
- Add `theme` property to `AppPreferences`
- **File**: `Sources/Preferences/PreferencesView.swift`
- Add theme picker (System/Light/Dark)
- **File**: `Sources/App/App.swift`
- Observe `NSApp.effectiveAppearance` changes
- Update `menuEngine?.setTitleColor()` and `menuEngine?.setIcon()` on theme change

### 4. Density Modes (Compact/Normal/Comfortable)
- **File**: `Sources/Core/Models.swift`
- Add `Density` enum: `compact`, `normal`, `comfortable`
- Add `density` property to `AppPreferences`
- **File**: `Sources/Preferences/PreferencesView.swift`
- Add density picker
- **File**: `Sources/MenuEngine/MenuEngine.swift`
- Adjust font sizes and spacing based on density mode
- Compact: 11pt, Normal: 13pt, Comfortable: 15pt

### 5. Better Typography
- **File**: `Sources/MenuEngine/MenuEngine.swift`
- Use `NSFont.systemFont(ofSize:weight:)` for menu items
- Use monospaced numbers for speed values
- Add `.monospacedDigit` feature setting where available

### 6. Native Menu Styling
- **File**: `Sources/MenuEngine/MenuEngine.swift`
- Use `NSMenu` with `menuType: .popUp` for native appearance
- Add separator items between logical groups
- Use SF Symbols for all icons
- Add `attributedTitle` with proper font for speed values

### 7. Smooth Animations
- **File**: `Sources/MenuEngine/MenuEngine.swift`
- Use `NSAnimationContext` for menu item transitions
- Animate title changes when speed updates
- Respect `NSAccessibilityReduceMotion` setting

## Validation
- Type-check passes with 0 errors
- Build script passes
- DMG builds successfully
- App launches and shows speed in menu bar title
- Theme switching works
- Density modes adjust font sizes
- Menu bar width is stable across value changes
